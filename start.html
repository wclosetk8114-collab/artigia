PART 1 ・WHAT YOU CAN BUILD

何が作れるのか

紹介ページ／申し込みフォーム／診断ツール／記録アプリ　—　4種類、すべて書き出せます

OVERVIEW

4種類あります。
どれも本物として動きます。

見た目だけのモックではありません。フォームは送信でき、診断は集計して結果を出し、記録アプリはデータが残ります。書き出したHTML1ファイルだけで、すべて動きます。

TYPE 01

紹介ページ

サービスやお店の1枚ページ。キャッチコピー、特徴、料金、よくある質問、問い合わせボタン。要らない部分は空欄にすれば消えます。名刺の代わりにも、募集ページにも使えます。

TYPE 02

申し込み・予約フォーム

聞きたいことを1行ずつ書くと、その入力欄ができます。「日付」と書けばカレンダー、「メール」と書けばメール欄に自動で変わります。送信すると、内容が入った状態でメールが立ち上がります。

TYPE 03

診断ツール

質問と選択肢を書くと、答えを集計して結果を出す診断ができます。SNSから人を集めるのに、いちばん効くやつです。質問の数も結果の文章も、自由に書き換えられます。

TYPE 04

記録アプリ

項目を決めるだけで、入力・一覧・合計まで動くアプリになります。書いた内容は閉じても消えません。CSVでも書き出せます。こづかい帳、在庫表、練習の記録、なんでも作れます。

FAQ

つまずきやすいところ

本当にプログラミングの知識は要りませんか？

要りません。やることは、欄に文字を入れることと、色を選ぶことだけです。コードを見ることもありません（見たい人は見られます）。

作ったものを、ネットに公開できますか？

できます。書き出されるのはHTMLファイル1つだけなので、無料で使える公開サービスにそのまま置けます。やり方が分からない場合は、オープンチャットで聞いてください。

スマホでも使えますか？

使えます。ただ、書きながら仕上げていく道具なので、パソコンのほうが快適です。作ったページ自体は、スマホでちゃんと見えるように作られます。

何回でも使えますか？

何回でも使えます。作りたいものが5つあるなら、5つ作ってください。書いた内容はブラウザに残るので、途中でやめて後から続きをやることもできます。

会員登録やログインのあるものは作れますか？

作れません。HTMLファイル1つで完結するところまでです。その先は、ツールの中の「AIに続きを頼む」ボタンから引き継げるようにしてあります。

本当に月額ではないんですか？

はい。500円を1回だけです。自動更新もありません。この先に90日のコミュニティはありますが、それは別のもので、入るかどうかはご自身で決めてください。

オープンチャットは実名ですか？

匿名で入れます。LINEのオープンチャットなので、本名も電話番号も他の参加者には見えません。表示名はその場で決められて、いつでも退出できます。

新しいPLUGは、いつ・いくつ増えますか？

できたときに追加します。数と時期は約束しません。「毎月かならず1つ」と決めると、中身より本数を優先することになるからです。
