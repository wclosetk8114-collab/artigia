01　作れるもの

4種類あります。
どれも書き出せます。

最初から見本が入っています。文字を自分のものに書き換えていくだけで、そのまま使えるものになります。色と書体は6通り×3通りから選べて、スマホでの見え方もその場で確認できます。

TYPE 01

紹介ページ

サービスやお店の1枚ページ。キャッチコピー、特徴、料金、よくある質問、問い合わせボタン。要らない部分は空欄にすれば消えます。名刺の代わりにも、募集のページにも使えます。

TYPE 02

申し込み・予約フォーム

聞きたいことを1行ずつ書くと、その入力欄ができます。「日付」と書けばカレンダー、「メール」と書けばメール欄に自動で変わります。送信されると、内容が入った状態でメールが立ち上がります。

TYPE 03

診断ツール

質問と選択肢を書くと、答えを集計して結果を出す診断ができます。SNSから人を集めるのに、いちばん効くやつです。質問の数も結果の文章も、自由に書き換えられます。

TYPE 04

記録アプリ

項目を決めるだけで、入力・一覧・合計まで動くアプリになります。書いた内容は閉じても消えません。CSVでも書き出せます。こづかい帳、在庫表、練習の記録、なんでも作れます。

02　使い方

やることは、3つだけです。

インストールもアカウント登録もありません。ブラウザで開いて、書いて、書き出すだけです。

STEP 1

書く

左の欄に文字を入れます。入れたそばから、右のプレビューが変わります。見本が入っているので、消しながら書き換えるのがいちばん早いです。

STEP 2

選ぶ

色と書体を選びます。白×紺、黒×金、生成り×茶など6種類。スマホでの見え方も、ボタンひとつで確かめられます。

STEP 3

書き出す

HTMLファイルが1つ手に入ります。ダブルクリックで開けます。人に送っても、ネットに上げても、そのまま使えます。

06　よくある質問

よくある質問

本当にプログラミングの知識は要りませんか？
要りません。やることは、欄に文字を入れることと、色を選ぶことだけです。コードを見ることもありません（見たい人は見られます）。
作ったものを、ネットに公開できますか？
できます。書き出されるのはHTMLファイルが1つだけなので、無料で使える公開サービスにそのまま置けます。やり方が分からない場合は、オープンチャットで聞いてください。
スマホでも使えますか？
使えます。ただ、書きながら仕上げていく道具なので、パソコンのほうが快適です。作ったページ自体は、スマホでちゃんと見えるように作られます。
何回でも使えますか？
何回でも使えます。作りたいものが5つあるなら、5つ作ってください。書いた内容はブラウザに残るので、途中でやめて後から続きをやることもできます。
会員登録やログイン機能のあるものは作れますか？
作れません。このツールで作れるのは、HTMLファイル1つで完結するものまでです。その先が必要になったら、ツールの中の「AIに続きを頼む」ボタンから、AIに引き継げるようにしてあります。
本当に月額ではないんですか？
はい。500円を1回だけです。自動更新もありません。この先に90日のコミュニティはありますが、それは別のもので、入るかどうかはご自身で決めてください。こちらから勧誘の連絡はしません。
オープンチャットは実名ですか？
匿名で入れます。LINEのオープンチャットなので、本名も電話番号も他の参加者には見えません。表示名はその場で好きに決められます。いつでも退出できます。
新しいPLUGは、いつ・いくつ増えますか？
できたときに追加します。数と時期は約束しません。「毎月かならず1つ」といった約束をすると、中身より本数を優先することになるからです。追加されたら、オープンチャットで無料でお渡しします。
返金はできますか？
デジタル商品のため、購入後の返金には応じられません。合うかどうか不安な場合は、上の「合う人・合わない人」を読んでから決めてください。
