投稿の「型」を10個つくる方法｜毎回ゼロから書かないための設計

公開：2026/10/19　文：つっちー＠結び代表

発信を仕組みにするとき、いちばん効くのが投稿の型です。型とは、どういう順番で書くかという骨組みのこと。これがあるとAIに頼んでもブレません。

自分の型は、過去の投稿から見つかる

自分の投稿のうち、反応がよかったものを3つ選んで、1文ずつ「これは何をしている文か」を書き出します。たいてい「問題提起 → 自分の体験 → 気づき → 問いかけ」のような共通の順番が見つかります。それが自分の型です。

よく使う10の型

  • 失敗型：やった → 失敗 → 原因 → いまどうしているか
  • 手順型：結論 → 必要なもの → 手順3〜5 → つまずきどころ
  • 反論型：よく言われること → でも実際は → 理由 → だからこうする
  • 質問型：もらった質問 → 前提 → 答え → 補足
  • 比較型：AとB → それぞれ向く人 → 自分の選択
  • 数字型：数字 → 背景 → 分かったこと（自分で測った数字だけ使う）
  • 変化型：前はこうだった → 何を変えた → いまこう
  • 裏側型：見えている結果 → 実際の作業 → 地味な部分
  • 道具型：困りごと → 使っているもの → 使い方 → 合わない人
  • 宣言型：やると決めたこと → 理由 → 期限
10個を一度に作る必要はありません。使いやすい3つから始めて、増やしていくほうが続きます。

型をAIへの指示文に組み込む

型を文章で書いておき、毎回その文を指示文に貼ります。「この順番で、1文ずつ短く、語尾は言い切り」と書くだけで、出てくる下書きの質が安定します。

型に頼りすぎない

同じ型ばかり続くと、読む側は飽きます。週のうち何本をどの型にするかを決めておくと、自然にばらけます。

まとめ

型は、書く時間を減らすためだけのものではありません。何を言いたいのかが自分でも整理されるので、投稿の中身そのものが良くなります。
